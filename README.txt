EMON NAME STYLE — GitHub Pages Website

Included:
- index.html: complete responsive name style generator
- Supports Free Fire, TikTok, YouTube and Facebook filters
- Search any name and generate hundreds of decorated variations
- One-tap copy buttons
- Fancy, Royal, Gamer, Cute, Symbol, Minimal, Fire and Pro categories
- Animated colors that change every second
- Mobile-friendly design; no Firebase or backend required

PUBLISH FROM ANDROID:
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Tap Add file -> Upload files.
4. Upload index.html to the repository's main/root folder.
5. Commit changes.
6. Open Settings -> Pages.
7. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
8. Wait a short time and open the GitHub Pages link shown there.

Note:
The generator creates variations algorithmically for any name; it does not contain a literal database of every name on Earth. Some decorative Unicode characters may not be accepted by every game or social platform.
